## 🌟 About ShopKart

**ShopKart** is a front-end e-commerce website project designed to provide a convenient and attractive online shopping experience.

Explore a variety of product categories, browse products, and discover a shopping interface built with HTML, CSS, and JavaScript.

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/luckyluckybaliyan-wq/SHOPKART.git
   ```

2. Open the project folder:

   ```bash
   cd SHOPKART
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
